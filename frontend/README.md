# Frontend | Start Students

Frontend da aplicação Start Students, desenvolvido com Angular 22.

## Executar o Projeto

Acesse a pasta do frontend:

```bash
cd frontend
```

Instale as dependências:

```bash
npm install
```

Inicie a aplicação:

```bash
npm run start
```


A aplicação ficará disponível em:

```text
http://localhost:4200/login
```
