# Backend | Start Students

Backend da aplicação Start Students, desenvolvido com Java e Spring Boot.

## Executar a Aplicação

Acesse a pasta do backend:

```bash
cd backend
```

Execute a aplicação:

```bash
./mvnw spring-boot:run
```

A API ficará disponível em:

```text
http://localhost:8080
```

## Documentação da API

Swagger/OpenAPI:

```text
http://localhost:8080/swagger
```

## Banco de Dados

Console H2:

```text
http://localhost:8080/h2-console
```
